모아갤 개인정보처리방침

시행일: 2025년 1월 1일  |  최종 수정: 2025년 7월 1일

모아갤(이하 "앱")은 사용자의 개인정보를 소중히 여기며, 관련 법령을 준수합니다. 본 방침은 앱이 수집하는 정보의 종류, 사용 목적, 보관 방법 및 사용자의 권리를 설명합니다.

1. 수집하는 정보

앱은 다음 정보를 수집하거나 접근합니다.

  • 캘린더 데이터 — Google 캘린더 연동 시 일정 읽기·쓰기 (사용자가 직접 연동한 경우에만)
  • 이미지 — 일기 작성 시 사용자가 직접 선택한 사진
  • 앱 사용 통계 — Firebase Analytics를 통해 화면 진입, 기능 사용 이력 등 익명 통계 수집
  • 오류 정보 — Firebase Crashlytics를 통해 앱 오류 발생 시 기기 정보 및 오류 로그 수집
  • 광고 식별자 — Google AdMob 광고 표시를 위해 광고 ID 사용
메모, 일기, 가계부, 일정 등 사용자가 작성한 모든 콘텐츠는 기기 내부에만 저장되며, 외부 서버로 전송되지 않습니다.

2. 정보 수집 목적

  • 앱 서비스 제공 및 기능 개선
  • 오류 감지 및 안정성 향상
  • 맞춤형 광고 제공 (Google AdMob)

3. 제3자 서비스

앱은 다음 제3자 서비스를 사용하며, 각 서비스의 개인정보처리방침이 적용됩니다.

  • Google Firebase Analytics — 앱 사용 통계 수집 (Firebase 개인정보처리방침)
  • Google Firebase Crashlytics — 오류 보고 (Firebase 개인정보처리방침)
  • Google AdMob — 광고 표시 (Google 개인정보처리방침)
  • Google Calendar API — 캘린더 연동 (선택 사항, Google 개인정보처리방침)

4. 요청하는 권한

  • 캘린더 읽기·쓰기 — Google 캘린더 일정 연동 (선택)
  • 알림 — 메모·일정 알림 발송
  • 인터넷 — Google 연동, 광고, Firebase 서비스
  • 저장소·미디어 — 일기 사진 첨부 및 백업 파일 저장

5. 데이터 보관 및 삭제

사용자가 작성한 데이터(메모, 일기, 가계부, 일정)는 기기 내부에 저장되며, 앱을 삭제하면 모든 데이터가 함께 삭제됩니다. Firebase 및 AdMob을 통해 수집된 통계 데이터는 각 서비스의 정책에 따라 관리됩니다.

6. 아동 개인정보 보호

앱은 만 14세 미만 아동을 대상으로 하지 않으며, 아동의 개인정보를 의도적으로 수집하지 않습니다.

7. 방침 변경

본 방침이 변경될 경우 앱 내 공지 또는 이 페이지를 통해 사전 안내합니다. 변경된 방침은 게시일로부터 효력이 발생합니다.
